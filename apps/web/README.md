# apps/web

Frontend Next.js 14. Entra em construção ativa na Fase 2. Duas visões
principais previstas no roadmap:

- `/entregador` — PWA mobile-first, lista de urgências, botão "assumir"
- `/solicitante` — dashboard com formulário de abertura + acompanhamento
  em tempo real via WebSocket

Autenticação via Firebase Auth (dois perfis: `SOLICITANTE` / `ENTREGADOR`).
